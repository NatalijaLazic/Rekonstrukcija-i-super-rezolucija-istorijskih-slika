# Preuzimanje i organizacija skupa podataka

Za projekat se koristi DIV2K skup podataka visoke rezolucije koji se standardno koristi za istraživanje super-rezolucije slika.

Dataset je dostupan na:
https://drive.google.com/drive/folders/1A776wkcNJ655KB1M8KV-zzC-iLPFTM9X?usp=sharing

Skup podataka se ne čuva u GitHub repozitorijumu zbog veličine (~4GB).
Potrebno ga je preuzeti sa gornjeg linka i raspakovati u folder `data/`.

Nakon raspakivanja, očekivana struktura foldera je:

data/
    DIV2K_train_HR/    (800 slika visoke rezolucije za trening)
    DIV2K_valid_HR/    (100 slika visoke rezolucije za validaciju)
